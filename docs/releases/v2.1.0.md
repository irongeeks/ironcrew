# OctoOffice v2.1.0 Release Notes

- Release date: 2026-03-16
- Scope: Full agent ecosystem expansion with pixel-art office rendering, mobile-responsive dashboard, light/dark theming, Obsidian knowledge base integration, OpenClaw CLI provider, CEO autonomous scheduler, and Projects view with GitHub PR integration.

## Highlights

### 1. Comprehensive Agent Ecosystem Expansion

- 14 agents defined across 7 departments: Planning, Development, Design, QA/QC, DevSecOps, Operations, and Knowledge.
- Each agent has a defined role, default system prompt, and assigned CLI provider.
- Department structure maps to named office zones in the Tiled office map for visual seat assignment.

### 2. Pixel-Art Character Sprites and Team-Based Positioning

- Agents rendered as pixel-art characters using walk/idle/down sprite sheets.
- Seat assignment driven by department zones defined in the Tiled office map (`Officenew.json`).
- Named seat objects (`Office{N}_seat{M}`, `Breakroom_seat{N}`, `Meeting_seat{N}`) control per-agent placement.
- Updated office map replaces the legacy layout with improved department zones and walkable areas.
- Clicking any department area opens a `DepartmentDetail` overlay showing the agent roster and live status.

### 3. Full Mobile-Responsive Dashboard

- All views — office, kanban, roster, and settings — adapt to phone and tablet screen sizes.
- Touch controls supported throughout; mobile uses a hamburger sidebar (`RetroSidebar`) and a bottom navigation bar.
- Desktop retains the `OctoOfficeTopBar` (46px) unified top bar with 7 tabs.

### 4. Retro-Themed UI Overhaul

- `Press Start 2P` pixel font applied globally to headers and labels.
- Pixel aesthetic extended to all components: cards, modals, badges, and status indicators.
- `image-rendering: pixelated` enforced for all sprite assets.
- Simplified layout with reduced visual noise across all views.

### 5. Light/Dark Mode Theming

- CSS custom-property-based theme system (`--bg-base`, `--accent`, `--border`, etc.) with `localStorage` persistence.
- Dark theme: near-black base (`#0d0d0f`) with emerald accent (`#34D399`).
- Light theme: `#fafafa` base with darker emerald (`#10B981`).
- Theme toggle available in the header; applies instantly without page reload.

### 6. German Language Support

- `de` locale added to the collaboration system, seed data, and status labels.
- Agents now match the user's language across KO/EN/JA/ZH/DE.
- Non-English locale instructions strengthened; fallback replies simplified.

### 7. Obsidian Vault Knowledge Base Integration

- Bidirectional sync between an Obsidian vault and agent worktrees.
- Before task execution, vault files are copied into `.octooffice/docs/<provider-id>/` inside the agent worktree.
- After execution, changes sync back to the vault automatically.
- Project bindings are configurable per agent in Settings > Knowledge.

### 8. Projects View with GitHub PR Integration

- New dedicated Projects tab showing GitHub pull requests, git status monitoring, and branch overview per project.
- New projects are created with sequential numeric IDs under `workspaces/PRODUCTION/`.
- New `GET /api/projects` endpoint backing the Projects view.

### 9. OpenClaw CLI Provider

- New `openclaw` adapter supporting per-agent profile isolation via `--profile <name>`.
- Isolated state stored at `~/.openclaw-<name>/`; config path overridable via `OPENCLAW_CONFIG` env var.
- Uses `--message` flag for input rather than stdin, unlike other CLI providers.
- Provider key `openclaw` is usable in the `cli_provider` agent column immediately after installation.

### 10. CEO Orchestrator and Autonomous Scheduling

- Removed browser testing department and provider from the default configuration.
- Added an autonomous CEO scheduler that reviews the inbox, creates tasks, reprioritises the queue, and auto-approves reviews on a configurable periodic tick.
- Autonomous mode is toggled in Settings > General.
- Autonomous scheduler is blocked from running tasks with pipeline phases awaiting manual approval.

### 11. Expandable Terminal Logs in Operations Center

- Session cards in the Operations Center now include collapsible terminal output panels showing live agent run logs.

### 12. Fixes

- Refined internal work narration detection to reduce false positives in agent output parsing.
- Removed CLI providers from LLM API server allocation to prevent misrouting.

## API and Behavior Notes

- New endpoints:
  - `GET /api/projects` — GitHub PR and git status data for the Projects view.
  - `/api/ops/servers` routes — server-to-agent binding management.
- OpenClaw adapter uses `--profile <name>` flag; config path via `OPENCLAW_CONFIG` env var.
- CEO Orchestrator autonomous mode toggled in Settings > General.

## Compatibility Notes

- Existing `development` pack behavior is unchanged.
- OpenClaw requires a separate CLI installation (`npm i -g openclaw`).
- Obsidian sync requires the vault path to be configured in Settings > Knowledge.
- The legacy office map (`office_map.json`) has been replaced by `Officenew.json`; custom seat overrides referencing the old map will need to be remapped.

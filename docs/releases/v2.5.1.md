# OctoOffice v2.5.1

**Released:** 2026-04-28

Post-release hardening and polish on top of the v2.5.0 rebrand. No breaking changes.

## What's New

### Mobile
- Agent picker in the Chat Panel — switch the active agent without leaving the chat view.
- Multiple polish passes: header, bottom sheet, tab bar typography, Projects view, Mission Control tabs, Terminal panel header.

### Security & Reliability
- Fixed auth noise, New Pack dialog race, `branches` endpoint, and a CSRF token race condition on session restore.
- Dependency security patches via pnpm overrides: `@xmldom/xmldom >=0.8.13`, `hono >=4.12.14`, `@hono/node-server >=1.19.13`, `postcss >=8.5.10`.
- Deep audit follow-ups: auth hardening, data validation, WebSocket safety, API shape consistency.

### CI & Testing
- E2E timeout raised to 60 minutes with list reporter for better visibility.
- Full E2E test suite now passes green: fixed pack-selector contamination, department ID casing, settings language selector, builder edge cases, SetupWizard overlay, CSRF token on realtime-updates, and WebSocket UI test flakiness.

### Cleanup
- Removed dormant design-checkpoint orchestration and the `tools/ppt_team_agent` submodule; reports now always produce a markdown deliverable.
- `templates/AGENTS-octooffice.md` restored so `pnpm run setup` works on a fresh clone.
- Personal identifiers in UI placeholders and test fixtures replaced with neutral RFC 5737 documentation values.
- Community health files (`CODE_OF_CONDUCT.md`, `CHANGELOG.md`, `CONTRIBUTING.md`) and `package.json` metadata aligned.
- Default team-leader agent names updated; README and Security docs polished.

## Upgrade

```bash
git pull
pnpm install
pnpm dev
```

No database migrations required.

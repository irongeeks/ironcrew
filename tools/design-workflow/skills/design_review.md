# design_review

## Purpose
Run design quality review before QA and approval.

## Review Checklist
- Visual consistency across screens and component variants
- Information hierarchy clarity
- Interaction and state completeness
- Handoff completeness (tokens, assets, behavior notes)

## Output Format
- Findings list with severity: critical/high/medium/low
- Decision: pass / revise
- Revision items mapped to concrete component or screen IDs

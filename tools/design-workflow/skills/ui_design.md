# ui_design

## Purpose
Produce high-quality UI/UX outputs that are implementation-ready and consistent with product constraints.

## Required Outputs
- Screen-level layout decisions (desktop/mobile)
- Component hierarchy with naming
- Interaction states (default, hover, focus, disabled, loading, error)
- Spacing scale and grid rules

## Guardrails
- Avoid visual-only descriptions; always define measurable layout constraints.
- Include at least one accessibility checkpoint per major screen.
- Keep design decisions traceable to the task goal.

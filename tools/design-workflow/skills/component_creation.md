# component_creation

## Purpose
Define reusable components with clear variants and handoff-ready contracts.

## Required Outputs
- Component list with purpose and usage scope
- Variant matrix (size, emphasis, state)
- Token binding (color, typography, radius, spacing)
- Implementation notes (React/CSS mapping guidance)

## Guardrails
- Every component must include states and variant constraints.
- Prefer composition over one-off screen-specific component naming.
- Explicitly mark which components are design-system-level vs local.

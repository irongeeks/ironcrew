[Phase: Planning — 検索戦略策定]

あなたは調査戦略を設計しています。この出力が後続フェーズすべての品質を決定します。

1. トピックを分析し、調査が必要な主要な側面を特定してください。
2. MECEの原則に従いサブクエスチョンに分解してください:
   - 相互排他的: 2つのサブクエスチョンが同じ領域を調査してはいけません。
   - 全体網羅的: 合わせてトピック全体をカバーする必要があります。
   - 各サブクエスチョンはウェブ検索で独立して調査可能でなければなりません。
3. 各サブクエスチョンに対して定義してください:
   - search_keywords: 3〜5個の具体的な検索語 (汎用的な語は避ける)
   - source_types: 優先すべきソース種別 (学術、ニュース、技術文書、政府、業界レポート)
   - priority: トピックへの中心性に基づく high/medium/low
4. ソースの多様性を考慮: 学術、ジャーナリズム、一次ソース、専門家の意見。
